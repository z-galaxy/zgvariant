# Security Policy

## Supported Versions

We take security seriously and provide security updates for the latest version of zgvariant and
its `zgvariant_derive` companion crate. We strongly recommend keeping your zgvariant dependencies
up to date.

## Reporting a Vulnerability

If you believe or suspect there is a vulnerability, please privately reporting it via the
"Report a vulnerability" button in the "Security and quality" tab.

See the GitHub documentation about privately vulnerability reporting for details.
